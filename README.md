# Charlotte Academic Website

This is a simple static academic homepage starter.

## Open it locally
Double-click `index.html` in Finder, or open it in any browser.

## Files
- `index.html` — all page content
- `styles.css` — design and layout

## Next steps
1. Replace `Charlotte` with your full professional name.
2. Add your profile photo.
3. Add email, CV, LinkedIn, Google Scholar, and GitHub links.
4. Connect the U.S. Economy section to live data.
5. Add an economics conference calendar.
6. Deploy using GitHub Pages or another static-site host.

This version intentionally uses no framework, so it is easy to edit and hard to break.
